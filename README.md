# thalictrum_sse8
RevBayes code for All traits considered: The role of trait combinations in lineage diversification


## Author: Rosana Zenil-Ferguson. 
Last updated September 25th, 2026. For more information reach out to roszenil(at)uky(dot)edu

## basicdata folder 

- eightstate_nooutgroup.tsv (.csv): Tabular separated data with eightstates for Thalictrum taxa that represent the combination of three traits without the outgroup.
- thalmatchphy_nooutgroup.tre (.nexus): Ultrametric bifurcating phylogenetic tree with Thalictrum taxa without outgroup that matches data above. 
- Originaldata_Jun24.csv: Comma separated value file with original data for Thalictrum.

## musse8

- musse8state_noutgroup.Rev: RevBayes code for musse with 8 states

## muhisse
- muhisse8state_nooutgroup.Rev: File with the RevBayes code for a muHiSSE model with 8 main states and two hidden states.


## lumped

- muhisse8state_nooutgroup_lumped.Rev: RevBayes code for lumping in two groups 8 states (WPH and WPU as group 1) to make the equivalent of a HiSSE model. 

## output

Folder with all the output files presented in the results.
